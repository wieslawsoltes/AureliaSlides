# Aurelia Slides

A plain HTML, CSS, and JavaScript presentation editor with a PowerPoint-style ribbon, an actual WebGPU renderer, and Canvas 2D fallback.

This repository is being initialized with the complete standalone application, editable source modules, zero-dependency build scripts, and 34 kernel tests.

The application runs without a framework, package installation, account, or external assets. Open `index.html`, or serve the directory using `python3 -m http.server 8000`.

The source import is checksum-verified before files are committed. The complete README is included with the application source.
